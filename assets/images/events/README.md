# Events photos

Place the Events page photos in this folder with these filenames:

- `events-hero-poster.jpg` — hero poster and still-image fallback
- `arabic-classes-featured.jpg` — featured Arabic class image
- `arabic-classes-card.jpg` — Arabic class carousel card
- `community-video-poster.jpg` — Moments video poster and fallback
- `community-gallery-01.jpg` through `community-gallery-03.jpg` — Moments gallery
- `newsletter-signup.jpg` — newsletter popup on Events and event-detail pages

The page uses these paths directly; no layout changes are needed. To use
different filenames, update the matching image paths and alt text in
`js/events-data.js`. Until a file is added, its existing box displays a
brand-colored placeholder rather than reusing a photo from another page.

Use optimized JPG, PNG, or WebP images. Keep faces and other important subjects
near the center so the responsive image crops remain composed.
